# Architecture decisions

Architecture Decision Records explain significant project decisions, their context, rationale, consequences, and trade-offs.

The following accepted decisions form part of the public documentation set:

| Decision | Status | Summary |
| --- | --- | --- |
| [ADR-001](ADR-001-business-driven-enterprise-modelling.md) | Accepted | Model business-first organizations. |
| [ADR-002](ADR-002-separation-of-simulation-and-learning.md) | Accepted | Keep simulation and learning concerns separate. |
| [ADR-003](ADR-003-value-driven-enterprise-generation.md) | Accepted | Generate enterprises from value and business definitions. |
| [ADR-004](ADR-004-conceptual-models-and-technology-implementations.md) | Accepted | Separate conceptual models from technology implementations. |
| [ADR-005](ADR-005-separation-of-enterprise-definition-generation-and-simulation.md) | Accepted | Separate enterprise definition, generation, and simulation. |

Accepted decisions are authoritative within their stated scope. Proposals and future considerations do not supersede them unless a later accepted decision explicitly records the change.
