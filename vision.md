# Vision

Status: Evolving public vision

Modern enterprises are living systems. People join, move between responsibilities, and leave. Organizational structures and business priorities change. Identities, applications, infrastructure, knowledge, permissions, and policies evolve with them. Decisions in one part of an enterprise create consequences elsewhere.

Training environments often isolate a technology or reproduce a predetermined exercise. That can teach a procedure, but it does not always show why the technology exists, how it supports the enterprise, or how business and organizational change create operational and security outcomes.

Enterprise Modelling & Simulation explores a different approach: represent the enterprise first, then derive coherent structures, relationships, changes, and scenarios from that context.

The long-term vision is an extensible platform in which fictional enterprises can be explored from multiple professional perspectives, including Identity and Access Management, cloud and infrastructure, security operations, detection engineering, governance, and related disciplines.

The project is intended to help learners and practitioners develop systems thinking. It connects technical decisions to enterprise purpose, responsibilities, people, knowledge, technology, risk, and operations rather than presenting systems as isolated products.

The conceptual core remains vendor-neutral. Domain Profiles and implementation layers can introduce discipline-specific and vendor-specific detail while preserving the underlying enterprise model.

IAM is intended to become the first Domain Profile, but work on that profile has not started. The enterprise core and enterprise generation foundations must be completed first. This dependency is deliberate: future IAM scenarios and methods should emerge from a coherent enterprise model rather than define that model prematurely.

This repository documents that vision, the decisions supporting it, and selected models and methods. The software implementation remains private and is not distributed here.
